 E-Commerce Sales Data Analysis (SQL Project)

Project Description
 This project analyzes an e-commerce sales dataset using SQL. The objective is to understand sales performance, product demand, and   regional sales trends.

 Tools Used
- MySQL
- SQL

Dataset Information
The dataset contains order-level sales data including product details, customer region, quantity, sales amount, and profit.

Key SQL Operations
- Data selection using SELECT
- Data filtering using WHERE
- Sales aggregation using SUM()
- Grouping using GROUP BY
- Sorting results using ORDER BY


## Insights Generated
- Top selling product categories
- Region-wise sales performance
- Monthly sales trends

## Conclusion
This project demonstrates how SQL can be used to analyze business data and generate useful insights from sales datasets.
